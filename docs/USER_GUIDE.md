# 使用手册

## 启动与登录

完成 `DEPLOYMENT.md` 后运行 `start-vibe-trading.cmd`。平台只监听本机
`127.0.0.1:8765`，密码来自 `.env` 的 `VIBE_UI_PASSWORD`。

## 运行研究

先确认账户、排行榜和新闻分别显示可用；读取失败不会被解释为空账户、零持仓
或零委托。点击“开始研究”后，后台依次完成 Universe、300、60、20、10–15
和逐股复核。进度来自真实 checkpoint，不是计时动画。

盘前 Universe 的行情参考日是上一已完成交易日，盘后使用当天。运行文件保存
在 `.local/research-runs`，不会进入 Git。

## 阅读 S5/S6

S5 的 KEEP 只是研究候选，不等于可买；WATCH 不允许增加仓位。新闻始终作为
不可信证据处理，不能充当提示词指令。

S6 使用新的账户、行情、费用和规则计算当前数量、目标数量、差量、费用和
现金底线，并检查 T+1、涨跌停、停牌、行情时效及外部委托。有 blocker 的
计划不能执行；刷新会生成新计划和新 hash。

## 人工确认

普通启动脚本只生成研究和组合草案，不开启买卖撤单。另行验证执行环境后，
仍必须核对精确 hash、股票、方向、股数、限价、费用和顺序再确认。

“已受理”不等于成交。UNKNOWN 不得重试，必须通过精确 broker order ID 和
证据记录解除锁。

## 常见阻塞

- S5 `NOT_CONFIGURED`：补齐 `RESEARCH_LLM_*`。
- Tushare 失败：检查 token/base URL，不要把 token 写进仓库。
- S6 缺费用/手数：提供权威 `NINEF_MARKET_PROFILE`。
- 有未结委托：读取最终状态，不能仅按时间假定失效。
- 周末/休市：历史结果可查看，盘中研究不能作为当前执行计划。
